# Fix: EPUB won't open, PDF scroll, and "open into reading mode"

## Problem
After running the app:
1. **EPUB books do not open** (blank / nothing happens).
2. **PDF opens but cannot be scrolled** between pages.
3. Expected behavior: tapping any EPUB or PDF should go **straight into book reading mode**.

## Root-cause analysis

### EPUB (blank, silent)
- All WebView errors are swallowed: `ReaderScreen.tsx:77-78` does `console.warn('[Reader]', message)` only. A failure in the epub.js engine or the RN↔Web handshake therefore shows as a blank white screen with no feedback.
- The book is rendered by `epub.js` running **inside a React Native WebView** (`src/epub/EpubReader.tsx` + `assets/web/reader.html`, generated by `scripts/copy-web-deps.js`). The RN side only sends `init` after the web posts a `boot` event. If that event is missed (timing, engine load, or `ePub` global not ready), nothing ever renders and there is no retry.
- `</script>` breakage is ruled out (only 2 legitimate closing tags in `reader.html`).
- `react-native-pdf`-style native issues don't apply here; epub.js is pure JS but depends on the engine actually executing and a working message bridge.

### PDF (scroll)
- `src/pdf/PdfReader.tsx:35` uses `style={{ flex:1, width:'100%', height:'100%' }}`. `react-native-pdf` needs a bounded, flex height and `enablePaging={false}` (continuous vertical scroll). `height:'100%'` + default paging is the classic "can't scroll" symptom.

### UX (open into reading mode)
- `LibraryScreen.tsx:70` and `SearchScreen.tsx:60` navigate to **BookDetails**, not **Reader**. Only `ReadingNowScreen` opens the reader (`ReadingNowScreen.tsx:49,80`). Tapping a book should open reading mode directly; details/delete should be reachable from inside the reader.

## Plan (ordered)

### 1. Surface EPUB errors visibly (diagnose + UX)
- In `ReaderScreen.tsx`, replace the silent `onError` with a **visible error overlay** (message + Retry button) and log the raw WebView message in dev. This alone makes the real cause visible.
- In `assets/web/reader.bootstrap.js`, wrap engine calls in try/catch and `post({type:'error', message})` with clear text (e.g., `ePub is not defined`, `book load failed`, `renderTo failed`).

### 2. Load the epub.js engine reliably
- Change `scripts/copy-web-deps.js` to generate `reader.html` that loads epub.js from a **CDN** (`https://cdn.jsdelivr.net/npm/epubjs/dist/epub.js`) instead of inlining ~600KB, and keep the small `reader.bootstrap.js` inlined. CDN loading avoids any Metro/UMD/global-name quirk of the inlined copy and is already consistent with the Google-Fonts CDN usage.
- Add an engine guard in the bootstrap: if `typeof ePub === 'undefined'`, post a clear error and stop.
- (Offline follow-up, optional): vendor epub.js by reading its text from a bundled asset and injecting via `injectJavaScript`.

### 3. Harden the RN↔Web handshake
- In `EpubReader.tsx`, send `init` **on WebView `onLoadEnd`** (after a short delay), not only on the web `boot` event. Make `init` idempotent (guard against double-open).
- Let the web also re-emit `boot` (or respond to a `requestInit` message) so handshake is resilient to ordering.
- Ensure `rendition` sizing uses explicit dimensions from `#viewer` (`clientWidth/clientHeight`) with a `100%` fallback, so pagination renders even if the flex height isn't reported immediately.

### 4. Fix PDF scrolling
- In `PdfReader.tsx`: change style to `style={{ flex:1, width:'100%' }}` (drop `height:'100%'`), add `enablePaging={false}`, `fitPolicy={0}` (fit width), and keep the wrapper `View` as `flex:1`. Ensure `readerArea` in `ReaderScreen` remains `flex:1` (it is).
- If still clipped, give the PDF an explicit height from `Dimensions.get('window').height` minus header/footer.

### 5. Open directly into reading mode
- Change `LibraryScreen.tsx:70` and `SearchScreen.tsx:60` to `navigation.navigate('Reader', { bookId: item.id })`.
- Add an **info/“Details” button** in `ReaderScreen` (header) that navigates to `BookDetails` for metadata/delete. `BookDetailsScreen` already exists and is reachable.

## Validation
- `npm test` still passes (Bengali + EPUB pipeline unaffected).
- Rebuild the dev build (`eas build --profile development` or `npm run ios/android`).
- Open: (a) a normal Unicode EPUB, (b) a Bijoy-encoded EPUB (auto-converted), (c) a PDF.
- Confirm: EPUB renders and pages turn; PDF scrolls through all pages; tapping a book anywhere opens reading mode directly; any engine error now shows an on-screen message instead of a blank screen.
